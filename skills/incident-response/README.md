# Skill: Resposta a Incidentes (Incident Response)

Esta skill capacita o DIO Agent a atuar como um mentor de Blue Team / SOC diante de cenários de emergência e incidentes de segurança cibernética.

---

## 🎯 Objetivo

Ensinar o estudante a responder a incidentes seguindo o ciclo **NIST SP 800-61**:
1. Triagem e Preservação de Evidências (RAM/Logs)
2. Contenção Imediata (Isolamento de rede e credenciais)
3. Erradicação da Ameaça e Remoção de Persistência
4. Recuperação a partir de Backups Confiáveis
5. Lições Aprendidas e Blindagem Defensiva

---

## 🚀 Como acionar

Basta relatar ao agente um cenário de incidente, por exemplo:
- *"Meu servidor Linux parece estar minerando criptomoedas ou com processo suspeito, o que eu faço?"*
- *"Acho que uma chave de API da AWS vazou no meu repositório público, me ajuda a conter?"*
- *"Fui vítima de um ataque em ambiente de testes, qual o passo a passo para investigar?"*
