# Skill: Modelagem de Ameaças (Threat Modeling)

Esta skill capacita o DIO Agent a atuar como um Arquiteto de Segurança de Software, guiando sessões práticas de modelagem de ameaças antes ou durante o desenvolvimento de sistemas.

---

## 🎯 Objetivo

Ensinar o estudante a aplicar a metodologia **STRIDE** da Microsoft:
- **S**poofing (Falsificação)
- **T**ampering (Adulteração)
- **R**epudiation (Repúdio)
- **I**nformation Disclosure (Vazamento de Informação)
- **D**enial of Service (Negação de Serviço)
- **E**levation of Privilege (Elevação de Privilégio)

---

## 🚀 Como acionar

Basta descrever uma ideia de sistema ou arquitetura, por exemplo:
- *"Estou desenhando uma API em Python para um sistema bancário, quais ameaças devo considerar?"*
- *"Como aplico o STRIDE para um sistema de e-commerce com microserviços?"*
- *"Quero fazer uma modelagem de ameaças para um aplicativo que usa banco de dados na nuvem."*
